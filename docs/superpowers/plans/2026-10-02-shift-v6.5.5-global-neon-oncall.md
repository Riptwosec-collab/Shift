# Shift v6.5.5 Global Neon + Individual Engineer Oncall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Shift v6.5.5 with one cohesive neon/cyber visual system across the application and an individual-centric Engineer Oncall view that clearly shows Today, Next, and a per-engineer × date monthly matrix.

**Architecture:** Preserve the existing single-file build and all v6.4–v6.5.4 behavior. Add a focused v6.5.5 visual layer (`src/v655-ui.css`) and extend the existing on-call model/rendering additively so old entry points, modes, data, localization, and performance controls remain intact. Generate `index.html` through the existing build script and gate the feature with a dedicated v6.5.5 regression suite plus the complete existing test suite.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Node.js 24, `node:test`, existing `scripts/build.mjs` single-file build, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-02-shift-v6.5.5-global-neon-oncall-design.md`

## Global Constraints

- Preserve existing application behavior, roster/on-call data, current views, navigation, and charts.
- Preserve TH/EN switching.
- Preserve HIGH/BALANCED/ECO behavior and respect `prefers-reduced-motion`.
- Keep Overview / Matrix / Timeline Engineer Oncall modes.
- Keep the generated single-file `index.html` production artifact flow intact.
- Prefer additive v6.5.5 CSS/JS changes over invasive rewrites.
- Do not hand-copy schedule data into the UI; derive it from `ONCALL_SCHEDULE` / existing model helpers.
- Dense matrices may scroll horizontally; mobile must remain usable.
- Feature branch name: `work/v6.5.5-global-neon-oncall`.
- App version after implementation: `6.5.5`.

## Review Focus

1. **Multiple engineers assigned on the same date:** Today/detail/matrix must render every assignment, not silently keep only the first.
2. **Months other than the current month:** initial selected date must be the first scheduled date rather than an invalid current-day carry-over.
3. **December 31 unassigned:** detail/matrix must show an explicit unassigned state and must not fabricate a person.
4. **TH/EN rerender after interaction:** selected engineer/day state must survive locale rerender while visible copy changes language.
5. **ECO / reduced-motion:** global neon visuals remain readable while continuous animation and expensive effects are disabled/reduced.
