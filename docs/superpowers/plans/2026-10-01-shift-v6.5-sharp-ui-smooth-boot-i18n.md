# Shift Command Center v6.5 — Sharp UI + Smooth Boot + TH/EN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the approved v6.4 legacy UI with sharper graphics, readable Thai/English typography, a smooth compositor-friendly boot path, complete TH/EN switching, and clearly distinct HIGH/BALANCED/ECO profiles without removing or redesigning existing UI or features.

**Architecture:** Keep `src/legacy-baseline.html` as the structural shell. Add a centralized i18n dictionary/controller, a v6.5 localization/runtime adapter, and a dedicated `v65-ui.css` override layer loaded after v6.4 CSS. Preserve cached schedule models and lazy view mounting; locale changes affect presentation only, while performance modes control decorative runtime cost through centralized CSS/runtime hooks.

**Tech Stack:** Static HTML/CSS/vanilla JavaScript, Node.js built-in test runner, existing `scripts/build.mjs`, standalone `index.html`, Wrangler/Cloudflare Static Assets.

**Spec:** `docs/superpowers/specs/2026-10-01-shift-v6.5-sharp-ui-smooth-boot-i18n-design.md`

## Global Constraints

- Preserve all v6.4 panels, views, controls, schedule data, employee names, and existing features.
- Do not alter the October 2026 / 2569 shift schedule.
- Do not replace the legacy visual shell with a new layout.
- Do not remove visual structures to gain performance; BALANCED/ECO may reduce effects and motion only.
- Production remains a standalone `index.html` compatible with the current Cloudflare direct-deploy flow.
- Thai is the default locale for a fresh client; only locale preference is persisted locally.
- Employee names, D/N/O schedule values, and technical identifiers are never translated or mutated.
- English dates use Gregorian 2026; Thai dates use Buddhist 2569.
- Performance mode remains in-memory and defaults to BALANCED on every reload.
- HIGH is the full cyber experience; BALANCED is visibly calmer; ECO is a crisp static HUD with no continuous decorative animation.
- Keep the current 3000 ms loader target and 3600 ms hard safety exit unless fresh implementation evidence proves a small timing change is necessary.
- No `document.write()`, `DecompressionStream`, runtime gzip handoff, global body-scanning MutationObserver, or remote web-font dependency.
- Cloudflare direct deploy continues to publish only tracked production `index.html`; do not make deployment depend on `dist/`.

## Review Focus

- **Unavailable/corrupt locale storage:** invalid values or storage exceptions fall back to Thai without blocking startup. Covered by Task 1.
- **Locale switch with mounted views:** switching TH/EN updates visible static and dynamic copy while preserving selected day/person/view and schedule cache. Covered by Tasks 2–3.
- **Reduced-motion users:** `prefers-reduced-motion: reduce` overrides continuous decorative motion even when HIGH is selected. Covered by Task 5.
- **Narrow mobile + English labels:** navigation, mode/language controls, sticky summaries, and dialogs remain readable/tappable without clipping. Covered by Task 7.
- **Slow/partial boot:** heavy effects stay suspended until loader release and the hard exit still clears the overlay by 3600 ms. Covered by Task 6.
