# Shift Command Center v6.5 — Sharp UI + Smooth Boot + TH/EN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade v6.4 with sharper graphics, readable Thai/English typography, smoother startup, complete TH/EN switching, and clearly distinct HIGH/BALANCED/ECO modes without removing or redesigning existing UI or features.

**Architecture:** Keep `src/legacy-baseline.html` as the structural shell. Add a centralized i18n dictionary/controller, a v6.5 runtime/localization adapter, and a `v65-ui.css` override layer loaded after v6.4 CSS. Keep schedule cache and lazy view mounting language-independent; locale changes update presentation only, while one centralized performance profile controls decorative runtime cost.

**Tech Stack:** Static HTML/CSS/vanilla JavaScript, Node.js built-in test runner, existing `scripts/build.mjs`, standalone `index.html`, Wrangler/Cloudflare Static Assets.

**Spec:** `docs/superpowers/specs/2026-10-01-shift-v6.5-sharp-ui-smooth-boot-i18n-design.md`

## Global Constraints

- Preserve every v6.4 panel, view, control, feature, employee name, and exact October 2026 / 2569 31-day schedule.
- Do not replace/restructure the approved legacy visual shell.
- Do not hide/remove structural graphics for performance; only decorative intensity/motion may change.
- Thai is the fresh-client default; only locale preference is persisted locally.
- Employee names, D/N/O schedule codes, technical identifiers, and schedule data are never translated/mutated.
- English dates use 2026; Thai dates use 2569.
- Visual mode remains in-memory and defaults to BALANCED on reload.
- HIGH = full cyber; BALANCED = visibly calmer and materially lower-cost; ECO = crisp static HUD with no continuous decorative motion.
- Keep loader target `3000 ms` and hard exit `3600 ms` unless fresh evidence proves a small timing change is necessary.
- No `document.write()`, `DecompressionStream`, runtime gzip handoff, body-wide MutationObserver, or remote web-font dependency.
- Production stays standalone `index.html`; Cloudflare continues deploying root assets with `.assetsignore` allowlisting only `index.html` and must not depend on `dist/`.

## Review Focus

- **Broken/unavailable locale storage:** fallback to Thai without blocking startup — Task 1.
- **Locale switch after multiple views are mounted:** update visible copy while preserving selected day/person/view/mode/cache — Tasks 2–3.
- **Reduced-motion + HIGH:** OS reduced-motion preference still disables continuous decorative motion — Task 5.
- **Narrow mobile + long English labels:** navigation and controls remain readable/tappable — Task 7.
- **Slow boot:** effects remain suspended and overlay still exits by 3600 ms — Task 6.
