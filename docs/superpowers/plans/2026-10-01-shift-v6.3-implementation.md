# Shift Command Center v6.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor Shift Command Center v6.2.1 into a smoother v6.3 operations dashboard with a polished 3-second loader, lazy rendering, cached analytics, richer Daily/Team Network/Analytics workflows, command palette, mobile improvements, and a single-file production build.

**Architecture:** Keep immutable schedule data in a dedicated source module, derive all analytics through pure functions and a session cache, and mount views lazily through one shared app state. Development source is split into focused ES modules, then a dependency-free Node build script emits one standalone `index.html` for Cloudflare native Git deployment by concatenating modules in a fixed dependency order and removing only local import/export syntax supported by this project.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, ES modules for source organization, Node.js built-ins (`node:test`, `assert`, `fs`, `path`) for tests/building, no runtime libraries, Cloudflare native Git auto-deploy from `main`.

**Spec:** `docs/superpowers/specs/2026-10-01-shift-v6.3-design.md`

## Global Constraints

- Preserve every employee name exactly.
- Preserve all 31 schedule characters for every employee exactly.
- Internal `O` may remain the stored off-duty code, but all user-facing labels must display `OFF`.
- `D` is red, `N` is blue, `OFF` is green across all views.
- Production output remains one standalone `index.html` with no external runtime dependency.
- Do not add Remember Last View; do not persist page, selected date, selected employee, command history, or visual mode across reloads.
- Visual mode starts as `BALANCED` on every page load.
- Loader target visible duration is `3000 ms`; safety hard exit is `3600 ms` maximum.
- Cloudflare deployment remains native Git integration; do not add a GitHub Actions deploy workflow.
- No `document.write()`, runtime gzip/decompression handoff, or global full-body OFF-normalization observer.
- Risk thresholds: `LOW_STAFFING < 6`, `LOW_NIGHT_COVERAGE < 2`, `CONSECUTIVE_WORK >= 3`, `LONG_NIGHT_STREAK >= 3`, `D_N_IMBALANCE >= 3`, `HIGH_OFF_COUNT >= 5`.

## Review Focus

1. **Boundary days (1 and 31 October):** previous/next comparisons must show `N/A` rather than wrap into another month; covered in Task 5 tests.
2. **Zero-overlap Team Network:** relationship strength must return `0` without division-by-zero and still render a usable relation list; covered in Task 6 tests.
3. **Repeated navigation:** opening the same view repeatedly must not duplicate nodes, listeners, or timers; covered in Task 3 UI-state tests.
4. **Keyboard focus conflicts:** `/` and `Ctrl/Cmd+K` must not hijack typing inside inputs/textareas/contenteditable fields; covered in Task 8 tests.
5. **Low-power/mobile rendering:** ECO/mobile caps must reduce effects without changing data, loader timing, or interaction semantics; covered in Task 9 tests.
